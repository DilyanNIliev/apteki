Редакция на аптеките

Попълваш полетата, промените се пазят в този браузър. Накрая натискаш „Свали overrides.json“ (или „Копирай“) и ми го пращаш – аз го качвам и сайтът се обновява.

Общ час на отваряне за всички без такъв:

Настройка за запис в GitHub (еднократно)

В GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: само apteki; Permissions → Repository permissions → Contents: Read and write. Поставяш токена тук – пази се само в този браузър и се праща само към api.github.com.

Постави JSON от overrides.json и натисни „Зареди“.
